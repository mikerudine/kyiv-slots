# GDD — структура «одного дня» и 7 мини-игр

**Проект:** One Day in Kyiv  
**Репо:** [mikerudine/kyiv-slots](https://github.com/mikerudine/kyiv-slots)  
**Статус:** черновик на проверке  
**Языки UI/копирайта:** украинский + английский (UA + EN)  
**Стек (не меняем):** web / mobile, GitHub Pages, plain HTML/CSS/JS  
**Сеттинг:** Київ, осінь–зима 2026–2027. Тон — «день из жизни», ирония без нравоучений.

---

## 1. Высокая концепция

Игрок проживает один вечер после работы: с левого берега домой, через двор с собакой, ужин при фонарике, стирку, посуду и ночную тревогу. Каждая сцена — отдельная мини-игра со своей механикой. Общее — киевский быт, короткий юмор в HUD/копирайте, ощущение «успел / почти успел», а не мораль.

Публичное название и точный тон юмора — открытые решения (см. §8).

---

## 2. Мета-структура дня (2 варианта)

### Вариант A — Линейная цепочка (рекомендация черновика)

Фиксированный порядок из описания проекта. Между этапами — короткий интерстициал (1 экран текста + CTA «Далі / Continue»). Пропуск этапа недоступен в v1; провал мини-игры даёт «потертый» исход и всё равно пускает дальше (см. §5).

```
Переправа → Самокат → Прогулка с собакой → Последний процент
        → Стирка → Посудомойка → Ночная тревога → Итог дня
```

**Плюсы:** ясный нарратив «одного дня», проще баланс и QA.  
**Минусы:** повторные заходы однообразнее.

### Вариант B — Хаб «Домой» с обязательным ядром

После Переправы открывается хаб (двор / подъезд). Обязательны: Самокат *или* альтернативный «маршрут пешком» (заглушка), Прогулка, Последний процент, Ночная тревога. Стирка и Посудомойка — опциональны, но дают бонус к итогу. Порядок свободный внутри окна «вечера».

**Плюсы:** реиграбельность.  
**Минусы:** сложнее туториал и скоринг; риск «пропустить самое смешное».

> **Открыто для Миши:** A или B (или A для v1, B для v1.1).

---

## 3. Что живёт между этапами

| Ресурс | Как влияет | Сброс |
|---|---|---|
| **Счёт дня** | Сумма очков мини-игр (− штрафы) | В конце дня → экран итога |
| **Время «часа дня»** | Абстрактная шкала 17:00→02:00; Переправа масштабирует «минуту ≈ час» | Не стена смерти, только тон интерстициалов |
| **Усталость** | 0–100; растёт от провалов/долгих этапов, слегка замедляет реакцию в экшенах | −немного за удачную мини-игру |
| **Настроение** | good / ok / ragged — косметика копирайта + лёгкий множитель скоринга | Меняется по исходам |
| **Флаги дня** | Напр. `rain`, `alarm`, `blackout` — могут тонировать сцены (прогулка, тревога) | На день |

Сохраняем локально (`localStorage`) прогресс текущей сессии; облако не требуется для v1.

## 4. Карточки семи мини-игр

Порядок — как в описании проекта. Длительность — оценка «честной» попытки на телефоне.

### 4.1 Переправа *(Crossing)*

| | |
|---|---|
| **Жанр** | Пошаговая стратегия на таймер |
| **Фантазия** | После работы добраться с одного берега Днепра на другой: мосты/транспорт «переключаются», автобусы уезжают, очередь на маршрутку |
| **Цель** | Доехать домой на другой берег за минимальное «время» |
| **Правила** | Сетка точек (остановка / мост / переход / маршрутка). Каждый ход = 1 тик таймера. Игрок выбирает ребро; RNG/скрипт меняет доступность рёбер (мост закрыт, автобус ушёл, очередь +N). |
| **Таймер** | Старт ~60 «минут» UI ≈ 1 игровой «час» пути; чем меньше остаток потрачен — тем выше скор |
| **Win** | Достигнуть узла «правый/левый берег — дом» до 0 таймера |
| **Lose / ragged** | Таймер 0 → принудительный «дорогой такси» исход, низкий скор, +усталость |
| **Скоринг** | `base + timeBonus − queuePenalties` |
| **Длительность** | 3–6 мин |

### 4.2 Самокат *(Scooter)*

| | |
|---|---|
| **Жанр** | Side-scroller runner (Chrome Dino–like) |
| **Фантазия** | После переправы — самокат по киевской «велосипедной» полосе с ямами, лужами, внезапными самокатчиками |
| **Цель** | Проехать дистанцию / продержаться N секунд |
| **Правила** | Бег слева направо; прыжок / присед; препятствия и пикапы (кофе = щит на 1 удар) |
| **Win** | Финиш района или цель по дистанции |
| **Lose** | 3 столкновения → «пешком дотянули», малый скор |
| **Скоринг** | Дистанция + комбо без ударов |
| **Длительность** | 1–2 мин |

### 4.3 Прогулка с собакой *(Dog walk)*

| | |
|---|---|
| **Жанр** | 3-lane runner (Minions-style) + пуши воздушной тревоги |
| **Фантазия** | Прогулка: калюжи, злые псы навстречу, телефон забит тревожными уведомлениями |
| **Детали** | См. [`gdd-dogwalk.md`](./gdd-dogwalk.md); прототип: [/dogwalk/](https://mikerudine.github.io/kyiv-slots/dogwalk/). Рейкастер сохранён в [/raycaster/](https://mikerudine.github.io/kyiv-slots/raycaster/) |
| **Win / Lose** | Дистанция/скор; 0 жизней = конец; пуши не смахивать — проигрыш внимания |
| **Длительность** | 2–4 мин |

### 4.4 Последний процент *(Last percent)*

| | |
|---|---|
| **Жанр** | Готовка / сборка заказа (sushi/burger-like), **не** чистый спидран |
| **Фантазия** | Ужин при последних 5% фонарика телефона (блэкаут / «світла нема») |
| **Цель** | Собрать N блюд/тарелок по рецептам, пока «батарея» не села |
| **Правила** | Рецепты из 2–4 шагов; ошибка порядка = переделка; батарея тикает всегда, быстрее на «ярком» режиме фонарика (выбор игрока: видеть лучше / жить дольше) |
| **Win** | N готовых порций до 0% |
| **Lose** | 0% → холодный ужин, ragged-настроение |
| **Скоринг** | Порции × качество − переделки; бонус за остаток % |
| **Длительность** | 3–5 мин |

### 4.5 Стирка *(Laundry)*

| | |
|---|---|
| **Жанр** | Match-3 |
| **Фантазия** | Загрузить цветное в стиралку за 3 минуты, считать «кг» |
| **Цель** | Набрать целевые кг цветного белья |
| **Правила** | Классическое 3+ в ряд: носки / футболки / трусы (и т.п.). **Подвох:** белая вещь в тройке цветных сжигает часть результата штрафом (сгорает «кг» или множитель) |
| **Таймер** | 3:00 |
| **Win** | ≥ целевых кг к концу таймера |
| **Lose** | Ниже цели → «доварка» / низкий скор |
| **Скоринг** | кг − whitePenalties + combos |
| **Длительность** | ровно ~3 мин |

### 4.6 Посудомойка *(Dishwasher)*

| | |
|---|---|
| **Жанр** | Packing / головоломка в лабиринте секций |
| **Фантазия** | За те же ~3 минуты впихнуть максимум посуды в квадрат машинки |
| **Правила** | Секции = **рандомный лабиринт** перегородок. Посуда выдаётся по одной; уже положенное можно перекладывать, но таймер идёт. Поворот предмета на 90° |
| **Win** | Уложить ≥ целевого числа предметов без перекрытий |
| **Lose** | Таймер 0 с недобором — остаётся «в раковине» |
| **Скоринг** | items × densityBonus − movesWaste |
| **Длительность** | ~3 мин |

### 4.7 Ночная тревога *(Night alert)*

| | |
|---|---|
| **Жанр** | Item hunt / point-and-click |
| **Фантазия** | Из спальни в коридор: двери, пауэрбанки на зарядку, кот/собака, документы, скотч на окна — список «как в жизни» |
| **Цель** | Выполнить чеклист до/пока идёт сирена (мягкий таймер) |
| **Правила** | Комнаты-экраны; тап по хотспотам; инвентарь 3–5 слотов; некоторые пункты зависят от флагов дня (`blackout` → свечи вместо лампы) |
| **Win** | Чеклист ≥ порога (напр. 5/7) |
| **Lose** | Таймер/волна закончилась с недобором — «успели кое-как» |
| **Скоринг** | пункты × скорость первого безопасного состояния |
| **Длительность** | 2–4 мин |

## 5. Переходы и исходы

1. **Интерстициал** (UA/EN): 1–3 предложения + иллюстрация-пиксель + кнопка дальше.  
2. **Провал не блокирует день** в варианте A: пишем `outcome=ragged`, +усталость, реплика, переход дальше.  
3. **Retry** — опциональная кнопка «Ще раз» до интерстициала (лимит 1–2 на этап в v1).  
4. **Итог дня:** суммарный скор, короткий «отчёт смены» (какие этапы ragged), шаринг-текст UA/EN.

## 6. Целевая длительность сессии

| Режим | Оценка |
|---|---|
| Полный день (A, без ретраев) | **18–25 мин** |
| С 1–2 ретраями | 25–35 мин |
| Одна мини-игра из меню дев/практики | 1–6 мин |

Цель продукта: уложиться в «одну поездку в метро / один чай» ≈ 20 минут.

## 7. UA + EN

- Весь HUD, интерстициалы, чеклисты, итог — ключи i18n (`ua` / `en`), переключатель как в прототипе dogwalk.  
- Имена мини-игр: рабочий EN в скобках выше; финальные маркетинговые названия — на утверждение.  
- Копирайт: разговорный UA как основной «голос», EN — естественный, не дословный машинный.
