# GDD — Прогулка с собакой (raycaster + автомат условий)

**Проект:** One Day in Kyiv  
**Мини-игра №3** в цепочке дня (см. [`gdd-day.md`](./gdd-day.md))  
**Статус:** черновик на проверке  
**Решение Миши (2026-11-01):** вид — пиксельный pseudo-3D **raycaster** (Wolfenstein-like), без упрощения в top-down / «настоящий» 3D-engine. Это гиммик и прикол, не AAA-камера.  
**Прототип:** https://mikerudine.github.io/kyiv-slots/dogwalk/ · код `dogwalk/`  
**Языки:** UA + EN

---

## 1. Фантазия

Вечерний двор хрущёвки. Перед выходом игрок крутит **игровой автомат условий** (тот же дух, что корневой «киевский однорукий бандит»): выпадают погода, люди, поведение пса, городские помехи. Выпавшее становится **набором испытаний** на прогулке от первого лица в пиксельном дворе.

Цель игрока — **выгулять собаку и вернуться**, закрыв обязательные чеки условий, не потеряв пса и (по возможности) достоинство.

---

## 2. Петля сессии

```
[Интерстициал «Пора гулять»]
        ↓
[Слот условий]  →  выпало K∈[2..4] условия из пула ≥8
        ↓
[Raycaster-двор]  →  испытания по маппингу, таймер T
        ↓
[Итог прогулки]  →  win / ragged / fail → флаги дня + скор
```

- Слот крутится **один раз** за заход (ретрай = новый ролл, по правилам дня).  
- Условия **стекуются**: испытания параллельны, HUD показывает чеклист.  
- Таймер прогулки: **90–120 с** базы; отдельные условия добавляют/съедают время.

## 3. Автомат условий

### 3.1 Пул условий (≥8)

| ID | Условие (UA) | EN label | Категория |
|---|---|---|---|
| `rain` | Льє як з відра | Pouring rain | погода |
| `ice` | Ожеледиця | Black ice | погода |
| `dark` | Темно як у… дворі | Courtyard blackout | город / свет |
| `alarm` | Летить «бледіна» (тривога) | Air-raid alert | город |
| `stray` | Чужий пес на площадці | Stray / other dog | люди+псы |
| `neighbor` | Сусід з порадами | Advice neighbor | люди |
| `zoomies` | Пес у zoomies | Dog zoomies | поведение пса |
| `refuse` | Пес не робить справи | Stage fright | поведение пса |
| `leash` | Повідок плутається | Tangled leash | поведение пса |
| `mud` | Калюжі / багно | Mud puddles | двор |
| `kids` | Діти з м'ячем | Kids with a ball | люди |
| `delivery` | Кур'єр перегородив прохід | Courier blocks path | город |

Для v1 достаточно **первых 8–10**; `kids` / `delivery` — бэклог, если объём ок.

### 3.2 Слот: как крутим

- 3 барабана (как в корневом слоте) **или** один барабан ×3 независимых ролла без дублей.  
- Веса: чаще быт (`mud`, `neighbor`, `zoomies`), реже тяжёлые (`alarm`, `dark`).  
- Запрет тройки взаимоисключающих крайностей по желанию (напр. не три «городские катастрофы» сразу) — **открыто**.

### 3.3 Маппинг условие → испытание

| Условие | Испытание в raycaster | Успех проверки | Провал проверки |
|---|---|---|---|
| `rain` | Скольжение + лужи-спрайты; видимость/туман↑ | Пройти маршрут, не упасть 2+ раз (или «вытереть лапы» у коврика) | 2 падения → −скор, +грязь на псе |
| `ice` | Резкий inertia на поворотах; зоны «льда» на полу | Дойти без столкновения со стеной на льду | Столкновение → стан 1 с, −время |
| `dark` | Сильный fog / radius света от «фонарика» (конус) | Найти калитку/дверь домой по ориентирам | Выход за радиус → «заблудились», −время |
| `alarm` | Сирена (аудио+пульс HUD); NPC бегут к подъезду; таймер сжимается | За 45 с довести пса к подъезду **или** в укрытие (арка/тамбур) | Не успели → ragged, флаг `alarm` на день |
| `stray` | Спрайт чужого пса; наш пёс тянет (смещение камеры/скорость) | Удержать дистанцию / нажать «заспокоїти» пока полоска не полная | Псы «поздравки» → −скор, +время |
| `neighbor` | Billboard-NPC перегораживает проход, держит диалог | Дослушать 1 реплику **или** аккуратно обойти (штраф за грубый рывок) | Игнор рывком → сосед «обиделся», −настроение |
| `zoomies` | Пёс переодически срывается вперёд по nav-точкам | Догонять / не дать уйти дальше N клеток (HUD «Пес відстав») | Пёс ушёл за fog-dist → fail «потеряли» |
| `refuse` | Зоны «трава/дерево»; пёс отказывается, пока не сменишь 2–3 точки | Получить 1× «справи» (прогресс-бар у зоны) | Таймер 0 без дела → −скор (прогулка «для галочки») |
| `leash` | Периодический tangle: движение ограничено, нужен жест «розплутати» | Успеть распутать до 0 полоски | Тangle max → стан, пёс отходит |
| `mud` | Лужа = slow + грязь на спрайте пса; у двери — «витерти лапи» | Вытереть лапы перед входом | Войти грязным → штраф стирке дня (`laundryPenalty` флаг) |
| `kids` *(backlog)* | Мяч-спрайт; пёс может сорваться за ним | Остановить рывок / обойти площадку | Zoomies-forced |
| `delivery` *(backlog)* | Коробка/велокурьер блокирует клетку прохода | Подождать despawn или найти обход | Столкновение −скор |

### 3.4 Приоритет / конфликт

Если одновременно `zoomies` + `stray` — сначала стабилизировать своего пса, потом дистанцию до чужого (туториальная подсказка одной строкой).  
`alarm` перекрывает таймер: становится жёстким лимитом «до укрытия».

## 4. Успех / провал прогулки

### Итоги

| Исход | Условие | Эффект на день |
|---|---|---|
| **Win** | Все выпавшие обязательные проверки ✓ и пёс рядом у двери/подъезда, таймер > 0 | Полный скор этапа, mood↑ |
| **Ragged win** | Дверь достигнута, но 1 проверка провалена **или** таймер < 10% | 50–70% скора, +усталость, возможный `laundryPenalty` |
| **Fail** | Пёс потерян (`zoomies`/`stray`) **или** `alarm` без укрытия при жёстком правиле | Мин. скор, mood=ragged; в мета-варианте A всё равно идём дальше |

### Обязательный минимум (даже без слота)

1. Пёс в радиусе follow у выхода.  
2. Хотя бы одна «цель двора» (круг / дерево / калитка) посещена.  
3. Возврат к стартовой двери.

Слот **добавляет** поверх минимума.

### Скоринг (черновик формулы)

```
score = base
      + 100 * conditionsCleared
      + timeBonus
      − 40 * falls
      − 80 * dogLostEvents
      − mudPenalty
```

## 5. Спека камеры и мира (raycaster)

Явно: **не** real-time 3D engine. Классический DDA column renderer + billboard-спрайты.

| Параметр | Значение (v1 / spike) | Комментарий |
|---|---|---|
| Внутреннее разрешение | **320×200** | CSS upscale, `image-rendering: pixelated` |
| FOV | ~66° (`plane` length 0.66) | Как в классике |
| Высота стен | 1.0 клетка мира = полная высота колонны на perp=1 | Без переменной высоты в v1 |
| Сетка карты | **24×24** (spike); цель двора 32×32 max | 0 пусто, 1 кирпич, 2 гараж, 3 живая изгородь/дерево |
| Текстуры | 64×64 procedural / позже atlas | Хрущёвка, ворота, кусты |
| Пол / потолок | Affine floorcast + градиент неба | Дистанционный fog |
| Спрайты | Billboard, sort far→near, z-buffer vs стены | Пёс, лавка, киоск, лужа, NPC, чужой пёс |
| Пёс | Follow AI, дистанция ~1.35 клетки | HUD: поруч / йде / відстав |
| Управление desktop | WASD + стрелки (поворот) | Strafe на A/D |
| Управление touch | Левый виртуальный stick (move), правые кнопки ◀▶ (look) | Без gyro в v1 |
| Производительность | Цель ~60 fps mid-phone; spike ~60 desktop headless | См. `dogwalk/README.md` |
| Аудио (позже) | Шаги, лужа, сирена, гав | Не блокирует GDD |

### Сущности на карте (минимум)

- Стартовая дверь / подъезд  
- 1× площадка / дерево для `refuse`  
- 2× лавки, 1× киоск (атмосфера)  
- 2–4 лужи  
- Точки укрытия для `alarm`  
- Spawn для `neighbor` / `stray`

### Связь со слотом корневого сайта

Опционально: если глобальные флаги дня уже `rain`/`alarm`/`dark` — автомат **гарантирует** соответствующее условие в ролле (не дублировать баннеры зря).  
**Открыто:** жёсткая связь или независимый ролл.

## 8. Открытые вопросы для Миши

1. Сколько условий в одном ролле — **ровно 3** (как барабаны) или 2–4 по весам?  
2. **Fail = потеря пса** только, или ещё жёсткий fail по `alarm`?  
3. Нужен ли мини-слот **визуально тот же**, что корневой kyiv-slots, или отдельный UI?  
4. Порода / имя / цвет пса для финального спрайта?  
5. Можно ли в v1 ограничиться **одним двором**, или нужны 2 планировки?  
6. Связь с глобальными флагами слота/дня — гарантированный ролл или независимый?  
7. Разрешён ли позже тонкий WebGL column-path, если телефоны <45 fps, при том же геймдизайне?  
8. Текст «успел вытереть лапы» — влияет ли реально на мини-игру Стирка (`laundryPenalty`)?
