# Накопич кіловати

Triple Town–style merge on a 6×6 grid: place batteries and power gear, merge three-or-more orthogonally into the next tier, stash one piece, and trap «відключення» blackouts into lamps.

**Chain:** батарейка → павербанк → зарядна станція → генератор → сонячна панель → ТЕЦ

Score is accumulated кВт (localStorage best). Plain HTML/JS + `logic.mjs`. Run tests: `node logic-test.mjs`.
