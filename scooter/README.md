# Scooter — One Day in Kyiv

Side-scrolling scooter ride (left → right). Plain HTML5 canvas + JS, GitHub Pages.

## Controls
- **Accelerate:** ▶ button · `D` / `→`
- **Brake:** ◀ button · `A` / `←`
- **Jump:** ⬆ button · `Space` / `W` / `↑`
- **Pause:** ⏸ · `P` / `Esc`

## Hazards
Curbs, ramps (launch), generators, flower beds, parked cars (ride the roofs).
